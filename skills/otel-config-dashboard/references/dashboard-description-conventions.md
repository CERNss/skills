# Dashboard Description Unified Convention

This document defines one unified `description` convention for SigNoz dashboards generated by this skill.

## Unified Rule

Use exactly one sentence in this shape:

`<app> SigNoz 面板。基于<事实来源>定义的<指标与链路范围>设计，服务范围为<service list>，覆盖<关键链路列表>，不做兼容查询与假设扩展。`

## Rules

1. If a field has no evidence, omit it instead of inventing content.
2. Keep service and dependency names identical to source terms.
3. Do not add fallback/alias language unless explicitly requested.
4. By default, express selected metrics as implemented coverage.
5. Lite first row title must be `一屏总览（值班核心健康信号）`.

## Minimum Fields

1. Subject: `<app> SigNoz 面板`
2. Fact-source scope
3. Service scope (`service.name` list when available)
4. Coverage scope (business chains/dependencies/metrics backed by facts)
5. Constraint phrase: `不做兼容查询与假设扩展`

## Hard Checks

1. Single sentence only.
2. No claims beyond evidence-backed scope.
3. Keep terminology stable (`Overview` default, no `baseline/planned` split unless requested).
